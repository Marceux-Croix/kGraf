kGraf network test (Windows Firewall)
=====================================

What it finds out: whether Windows Firewall can block the network for
programs that kGraf runs in its sandbox, and not for you.

What it does: it copies curl.exe to C:\kgraf-fwtest, adds one firewall
rule that applies only to that copy, tries to reach example.com twice
(once as you, once in kGraf's sandbox), then removes the rule and the
copy. It installs nothing, and it removes what it added even if a step
fails. It takes about one minute.

How to run it
-------------
1. Open the Start menu and type PowerShell.
2. Right-click "Windows PowerShell" and click "Run as administrator".
   Click Yes.
3. Go to this unzipped folder. For example, if you unzipped it in
   Downloads (change the name to the folder you have):

   cd "$HOME\Downloads\kgraf-wintest-<version>-windows-x86_64"

4. Paste these three lines into the window, all together, and press Enter:

$dir="C:\kgraf-fwtest"; New-Item -ItemType Directory $dir -Force | Out-Null; Copy-Item C:\Windows\System32\curl.exe "$dir\curl.exe"
function T { "you:     " + (& "$dir\curl.exe" -sS -o NUL -w "%{http_code}" --max-time 15 https://example.com 2>&1); "sandbox: " + (& .\kgraf-wintest.exe sandbox-run -- "$dir\curl.exe" -sS -o NUL -w "%{http_code}" --max-time 15 https://example.com 2>&1) }
try { "--- before the rule"; T; $sid=([System.Security.Principal.WindowsIdentity]::GetCurrent()).User.Value; New-NetFirewallRule -DisplayName kgraf-fwtest -Direction Outbound -Action Block -Program "$dir\curl.exe" -LocalUser "D:(A;;CC;;;$sid)" | Out-Null; "--- with the rule"; T } finally { Remove-NetFirewallRule -DisplayName kgraf-fwtest -ErrorAction SilentlyContinue; Remove-Item -Recurse -Force $dir; "--- cleaned up" }

5. Send back a screenshot (or a copy) of what it printed.

How to read the result
----------------------
Before the rule, both lines must show 200. If not, the machine has no
network or a proxy blocks example.com, and the test does not count.

With the rule:

  you: error,  sandbox: error  -> Windows cannot tell the sandbox apart
                                  from you.
  you: error,  sandbox: 200    -> Windows can tell them apart: kGraf can
                                  block the network for its sandbox.
  you: 200                     -> The rule did not take effect; the test
                                  does not count.

If the last line is not "--- cleaned up", run these two lines to remove
the rule and the copy by hand:

Remove-NetFirewallRule -DisplayName kgraf-fwtest
Remove-Item -Recurse -Force C:\kgraf-fwtest
